# Как участвовать в разработке AGENT.ONE

Спасибо за интерес к проекту! Сообщения об ошибках и улучшения помогают развитию платформы.

## Локальный запуск
Следуйте [README_LOCAL_START.md](README_LOCAL_START.md). Для разработки нужны Go, Node.js, Docker и отдельная локальная PostgreSQL.

## Перед Pull Request
1. Создайте отдельную ветку и ограничьте изменения одной задачей.
2. Проверьте, что код не содержит реальные ключи, личные контакты, IP, SSH-файлы, дампы БД или приватные URL.
3. Выполните подходящие проверки:
   - `npm test --prefix client`
   - `npm test --prefix client-auth`
   - `cd server && go test ./cmd`
4. Приложите описание изменения и шаги для проверки.
5. Не добавляйте настоящие персональные данные и не подключайте тесты к production.

## Предложить идею
Откройте GitHub Issue и расскажите, какую проблему решает изменение. Для уязвимостей используйте [SECURITY.md](SECURITY.md), а не публичные Issues.

## Право на использование
У репозитория пока нет отдельной лицензии. Публикация исходного кода не означает автоматического разрешения на распространение модификаций или коммерческое использование.
