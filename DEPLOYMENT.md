# AGENT.ONE: самостоятельное развёртывание

Этот публичный исходный код не содержит конфигурацию действующего сервера автора.

Для локального запуска используйте README_LOCAL_START.md.

Для своей production-инсталляции необходимы отдельные:
1. Домен и HTTPS reverse proxy;
2. PostgreSQL, Redis и надёжное резервное копирование;
3. Пароли, JWT, OAuth/AI ключи, настроенные через окружение;
4. Контакты оператора данных и обязательные юридические документы;
5. Мониторинг, CI, проверка безопасности и процедура восстановления.

Шаблон конфигурации: .env.production.example. Шаблон контейнеров: compose.production.yml.

Не используйте локальные демо-пароли в публичном окружении.
