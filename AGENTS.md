# AGENT.ONE: инструкции участникам разработки

Платформа содержит основной React-клиент (client/), портал входа (client-auth/), Go API (server/), общие юридические компоненты (shared/legal/) и тесты (scripts/).

- Запуск должен работать независимо от пути клонирования, имени пользователя, ОС и буквы диска.
- Никогда не коммитьте производственные IP, SSH-конфигурации, API-ключи, базы данных, дампы или персональные контакты.
- Реальные ключи, домены и реквизиты задаются в своём окружении. Тестовые значения нельзя переносить в production.
- Изменения авторизации, платежей и безопасности должны сопровождаться тестами.
- Перед PR выполните сборки клиентских приложений и Go-тесты, затрагиваемые изменениями.
- Инструкция для пользователей: README.md и README_LOCAL_START.md.
